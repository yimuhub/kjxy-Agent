# 实施方案：智慧农业设施接入 + 农业 Agent 内置包（状态：已确认 2026-10-18）

**用户拍板**：① 连接器做通用四类通道不绑型号；② 暂无真实设备，用模拟设备源验收；③ 设备控制=只读+建议+一键工单/审批（不自动反控）；④ 开工顺序 B（技能包）→ A（设备接入）。

起草：2026-10-18 · 基座：声明式 Agent（M2）+ Agent 工厂（M3）+ 分级审核（ADR-0005），全部复用现有运行时。

## A. 智慧农业设施数据接入（devices 模块）

### 现实约束（调研结论）
- 行业惯例：现场设备（气象站/墒情/虫情灯/控制器）经**网关统一转 MQTT 或 HTTP** 上云；
- 主流平台（OneNET/阿里云IoT/华为云IoT）与厂商云（托普云农、奥诗恩、竞道、建大仁科等）**均有开放 API，但字段/鉴权/节奏各家不一**；
- RS485/Modbus 直连需要本地网关硬件，平台策略："**会说话 HTTP/MQTT 的都能接**"，Modbus 走厂商网关转换后接入；
- 视频流不接（不在 LLM 价值点，成本高），图片抓拍可走知识库上传路径。

### 架构：四类接入器 → 统一数据模型 → 三类消费
```
[A 厂商云API拉取(定时任务)] ┐
[B 自定义连接器(界面配置,零代码)] ├──→ 统一模型: device/metric/reading(时序) ──→ ①Agent 工具 sensor.query(只读)
[C Webhook 推送(HTTP+token)]   │              │                                ②阈值告警→站内通知/告警webhook
[D MQTT 订阅(broker配置)]      ┘              └→ 数据看板(图表/最新值/健康度)
```
- **统一字段映射**：连接器用 JSONPath/字段映射把各家报文归一到内置指标字典（气温/地温/湿度/降雨/风速风向/光照/CO₂/土壤水分×层/EC/pH/水位/虫情计数…），未识别字段进 raw 保留；
- **自定义连接器**（覆盖"任意自定义接口"诉求）：yard_admin 界面填写 名称/URL/方法/鉴权头(密文)/取数路径/字段映射/采集周期 → 平台定时拉取，SSRF 出网校验复用 net_guard，凭证 Fernet 加密复用供应商加密体系；
- **写控制红线**：设备反控（灌溉/风机/杀虫灯开关）默认**不做自动执行**——生成"建议+一键生成工单/审批申请"，走现有 workorder/审批闸门人工确认；确需直控的个别场景后续单独立项评估；
- Agent 消费：新只读工具 `sensor.query(device, metric, window)`，任何声明式 Agent/工厂角色的模板可引用"最近 24h 大棚数据"，诊断/灌溉建议就有实据。

## B. 农业 Agent / 技能内置包（skillhub 模块）

### 现实盘点（2026-10-18 GitHub 实测检索）
- 农业 agent 市场真实供给**少而散**：绝大多数是个人 hackathon 项目（FarmGPT、AgriMitra、KrishiSathi——印度场景、MIT）；
- 可直接吸收的高价值项：**farmfriend-labs/agent-skills-farming**（AgentSkills.io 格式，MIT，自然农法/蚯蚓/发酵/气象）、**AgriClaw**（MIT，积温/试验设计/土壤/气象的**科研管线**技能，格式规范）、**DeepLeaf Agronomist-1**（Apache-2.0，spec 先行、MCP 工具协议思路值得对表，权重 2026-11 才发布）；
- **AgriAgent(稷丰)** 等标注"仅供科研、禁止商用"——**不可内置**；无 LICENSE 仓库默认不采。

### 三层供给方案
1. **中文精选种子包（第一批 12-16 个，纯自产）**：用声明式 Agent 格式做成 `agriskills/<code>.yaml` 种子包入库，platform_admin 一键"装载内置包"（平台级全员可见，小院可 fork 定制）。角色规划：🌾病虫害初诊(拍照问诊引导)/🧪农药配制测算(标注安全间隔期免责)/🏠棚室环境管家(联动 sensor.query)/💧灌溉顾问/🗺️农机作业调度/🐄畜牧养殖辅助/📈行情情报员/🏛️惠农政策匹配/✍️农产品电商文案/🧫施肥配方/🔬测土配方报告/🚜收获储运/🌱苗情测报/📋农事日志。每个带：人设+模板+建议问题+冒烟题+免责声明；
2. **外部技能导入管道**：注册 GitHub 源 → 抓取 → 格式转换器（AgentSkills SKILL.md / CrewAI yaml / 自由 prompt → 声明式定义）→ **消毒器**（工具白名单重校验/提示注入扫描/LICENSE 识别，非商用许可自动拦截）→ 冒烟评估（复用 eval harness）→ **platform_admin 人审队列**（复用高风险审核 UI）→ 入库标注来源+LICENSE+链接；
3. **MCP 预留**：sensor.query/workorder 等工具按 MCP 资源描述导出，DeepLeaf 类外部智能体未来可挂接（本期只留接口文档）。

## 依赖与红线
不动 LLM 供应/鉴权/小院隔离既有纪律；外部技能一律走审核分级（含副作用或无知识范围 → 平台审核）；全链路审计；导入内容版权三件套（来源/LICENSE/作者）缺一不入库。
