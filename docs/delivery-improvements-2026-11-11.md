## 一、功能逐项审查结论（虚假/多余/重复/死码）

| 审查项 | 方法 | 结论 |
|--------|------|------|
| 虚假功能 | 全库 FakeProvider/占位/假成功路径扫描 | **唯一发现：pest_alert**（脚手架 FakeProvider 假 LLM）→ v3.76 已重造为真实链路 |
| 死链 | 392 条前端 API 调用 × 后端路由 + 427 条 openapi 契约归一化比对 | 零死链、零脱节 |
| 重复路由 | 前端路由表去重扫描 | 无重复（/login、/setup 各注册一次） |
| 孤儿代码 | 134 组件 + 全部视图引用图扫描 | 无孤儿组件/视图 |
| 死标记 | TODO/FIXME/console.log 全库扫描 | 前端零残留；后端仅剩 agents/scaffold.py（生成器模板，合法） |
| 假发送器 | 短信/邮件/webhook 假成功扫描 | 无（bots 适配器的 NotImplementedError 为注入模式，合法） |

## 四、改进路线（按交付价值排序，供客户排期）

1. **农产品质量溯源**（P1）：科技小院自产农产品的「地块-农事-投入品-检测-出库」链路溯源码；
   可复用 farm 台账 + knowledge 检索 + 二维码（qrcode 已有）底座
2. **日志合规辅助**（P2）：按「500 字 + 2 张照片」口径做撰写侧实时提示与达标自检；
   导出全国平台所需的日志包（含照片重命名规范）
3. **虫情测报灯设备接入**（P2）：devices 模块新增虫情测报灯设备类型（识别数量时序），
   喂给 pest_alert 做量化的虫口消长曲线，替代当前的定性风险提示
4. **水肥一体化联动**（P3）：灌溉设备控制指令下发（需硬件侧配合，当前 devices 只读）
5. **日志排行榜/院际评比**（P3）：对接全国平台口径的院内排行榜，牵引研究生日志质量
