## 第一章 系统简介与角色总览

本平台是**科技小院的数字中枢**：智能对话、工作日志、指挥官任务、知识库、
技能/插件市场、设备传感、培训与报告，全部在一个网页（+ 手机群聊）里完成，
把「负责人、研究生、技术员、专家、农户、学校」连成一体。

**登录后每个人看到的菜单不一样**（按角色自动裁剪），这就是「角色工作台」：

| 你是谁 | 登录后第一屏 | 截图 |
| --- | --- | --- |
| 平台管理员 | 今日工作台（全院视角） | `platform-admin-home.png` |
| 小院负责人 | 今日工作台 | `yard-admin-home.png`（与上图同布局，菜单略异） |
| 驻点研究生 / 技术员 | **工作日志**台 | `operatorjournal.png` |
| 专家 | 今日工作台（专家审核入口） | `exporthome → exporthome.png`（见 experthome.png） |
| 农户 | 手机群里 @机器人提问（无需装 App） | 见 §十二 |

平台右上角有拟人化「农民伯伯」伙伴：会随工作状态做动作（刨土/擦汗/摘草帽
扇风/点头），点击可打开快捷面板（对话/能力管理）。

## 第二章 登录、注册与邀请

1. **登录**：输入账号密码（连续输错默认锁定 10 次/5 分钟）。
2. **加入小院**：①管理员在「成员管理」直接创建账号；②管理员发**邀请链接**
   （`/invite/:token`），点开自动填入；③「开通新的小院」自助注册（审批模式由
   管理员配置）——注册页填「小院 ID」后**失焦自动核验**，立刻反显小院名称
   确认填对。
3. **改密/资料**：右上角头像 → 「个人资料」。

## 第三章 今日工作台（概览，登录第一屏）

`platform-admin-home.png`

- **智能问候**：按时间/天气/待办生成的行动提示（夜里会提醒休息）。
- **四张待办卡**：待处理工单 / 待专家复核 / 今日农事记录 / 未处理告警——

  直达详情。
- **快捷按钮**：记一笔农事 / 拍照诊断 / 上报告警 / 开始对话 / 生成本周报表。

## 第四章 工作日志（研究生 / 技术员 · 每日必用）

`operatorjournal.png`

对应全国科技小院平台的**日志/月报硬考核**（年 100 篇、常驻 120 天）。

1. **生成今日草稿**：平台把你当天的真实活动（咨询对话、发起任务、记的台账、
   设备处置）自动汇总成客观的日志草稿——只汇总事实，不含对话原文。
2. **核对补充**：草稿必须本人编辑确认（补上平台外的工作，如下田、开会）。
3. **提交**：进入「待审核」，由负责人/专家通过或驳回（驳回带意见，改后重交）。
4. **月报**：「生成本月月报草稿」按活跃天聚合；「**导出月报 Word**」一键下载，
   可直接贴进全国平台填报表单。
5. **年度达标牵引**：进度条显示「当年 X/100 篇 · 周均速率 · 预计全年总量」，
   进度偏慢会亮黄提示——把考核压力变成每天的日常牵引。

## 第五章 智能对话（所有人）

`expertchat.png / operatoryard_chat.png`

- **提问即答**：优先检索本小院知识库，回答**带引用来源**；依据不足时如实
  追问关键信息，不编造。
- **附件**：PDF/Word/Excel/图片/CSV 可上传，让助手读取分析。
- **生成文档**：「把这段整理成 Word/周报/PPT」→ 消息里出现下载卡。
- **一句话要技能/插件**：说「我需要一个病虫害防治的技能」→ 先检索现成的
  （候选卡片），没有就自动生成草稿（私有/待审，不自动上线）。
- **过程可见**：助手的多步执行（检索/工具调用）逐步显示。
- **一键复制**、历史会话管理、多会话并行。

## 第六章 指挥官工作台（目标 → 自动拆解执行）

`admincommander.png / operatoryard_commander.png`

1. 输入一句业务目标（如「整理本月病虫害防治情况并给下月建议」）。
2. 系统先产出**计划**（可能先追问澄清），你可编辑子任务再执行。
3. 执行时实时滚动每个子任务的进度/产出；可取消；失败可**只重试失败部分**。
4. **预算**：token 消耗与预算水位实时显示，超预算自动暂停。
5. 运行结束自动产出**汇总消息**与资产沉淀（成熟工作流/技能片段/失败黑名单）。

## 第七章 我的智能体

`adminagents_custom.png`

### 7.1 ⚡ 一句话生成（推荐）
「⚡ 一句话生成」→ 输入一句需求 → 四阶段进度（联网取证→设计框架→匹配技能
→保存草稿）→ **六段框架预览**（使命/对象/边界/工作流/护栏/产出格式）→
已匹配技能可解绑、待补技能可删 → 完成后直接进编辑弹窗。
生成结果一律是**草稿**，走发布闸门，不自动上线。

### 7.2 手工创建 / 编辑
- 填编码、名称、系统提示词、任务模板（必须含 `{{question}}`）；
- 「扩展技能 / 扩展插件」选择器：**默认最多显示 3 行**，更多内容点「展开全部
  N 项」在下拉弹框中选择（搜索过滤、全选/清空）；
- 知识范围（本小院/公开作物知识）、独立大模型与子模型指定。

### 7.3 列表与卡片（已绑技能折叠展示）
`adminagents.png`
绑定技能很多的智能体，卡片/列表上的技能标签云**默认只显示 3 行**，点
「展开全部 N 个 ▾」展开、「收起 ▴」收回——页面始终整齐。

### 7.4 发布闸门
草稿 →（发布）低风险直接发布 / 高风险进平台审核 → 已发布 → 可停用/回滚。

## 第十章 专家审核

`expertreview.png`

专家/负责人/管理员的审核中枢，四个队列：
1. **知识候选**（自我总结/运维产出）——逐条或批量通过/驳回；
2. **Skill 管理**——本院全部技能的定义、来源、风险；发布评测门禁自动跑；
3. **工作日志审核**——新提交的日志通过/驳回（驳回必须填意见）；
4. 诊断复核（待专家复核的用药建议）。

## 十四、枢纽工作台（运营模式 · 通用基座）

`platform-adminhubs.png / experthubs.png`

平台是**通用基座**，其上按治理形态选择运营模式（新建枢纽时三选一）：

| 模式 | 原型 | 侧重 |
| --- | --- | --- |
| 省级科协模式 | 江苏（培养单位枢纽，小院跨市分散） | 达标监测、按单位聚合 |
| 市级全域模式 | 邯郸（一市专班，县域全覆盖） | 全域推广进度、断更跟进 |
| 实验站枢纽模式 | 曲周（实验站统管小院群） | 小院群横向对比、一院一策 |

操作：创建枢纽（选模式）→ **绑定小院**（下拉直选你有权管理的小院）→
**添加成员**（下拉直选 manager/viewer）→ 查看所辖小院聚合（日志量/活跃
作者/**断更 7 天预警**，只出数字不出内容）。小院被绑定后，该院负责人/管理
员登录也能看到所属枢纽的聚合视图。

## 十六、FAQ

**Q1 回答说「依据不足」？** 这是设计：不编造。补上地块/生育期/照片会得到更
准的回答。

**Q2 生成的东西直接上线吗？** 不会。全部草稿/待审，走闸门。

**Q3 日志草稿不全？** 草稿只聚合平台内活动，平台外工作请在编辑框补充——
提交前以你确认的为准。

**Q4 搜索部分源不可用？** 搜狗/360 可能被反爬（正常），必应为主源可完整服务；
需要更强搜索配 Tavily Key 或启用本地 SearXNG。

**Q5 生成次数用尽 / token 预算触顶？** 管理员在系统设置调整；指挥官预算在
设置里可调。

**Q6 忘记密码 / 账号锁定？** 联系管理员重置/等待锁定期。

## 十七、已知边界（诚实说明）

1. 官方模型购买目前为订单占位展示，不完成真实支付；
2. 搜狗/360 源可能被对方反爬（必应为主源，功能不受影响）；
3. 所有生成结果不自动发布（安全设计）。
