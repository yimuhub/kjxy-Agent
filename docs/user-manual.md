# 科技小院智能体平台 · 系统操作说明书

> 版本：v3.64.0（2026-11-04）
> 适用对象：小院负责人（教授/首席专家）、小院管理员、驻点研究生、专家、
> 工作人员（技术员）、农户、学校/平台管理员
> 阅读方式：先看「一、角色总览」找到你的身份，按目录跳到对应章节。

---

## 一、系统是什么，你能用它做什么

本平台是**科技小院的数字中枢**：一个网页（+ 手机群聊）里，集成了智能对话、
工作日志、任务与设备、知识库、技能/插件市场、培训与报告等能力，把「负责人、
研究生、技术员、农户、学校」五类人连在同一个系统里。

一句话概括各角色的用法：

| 你是谁 | 登录后第一眼 | 你最常用的三件事 |
| --- | --- | --- |
| 小院负责人 | 概览行动板 | 看周报推送、审批、导出月报给学校 |
| 小院管理员 | 概览行动板 | 成员管理、官方技能包、系统设置 |
| 驻点研究生 | **工作日志**台 | 生成日志草稿→提交、跑指挥官任务、做培训课件 |
| 专家 | 概览行动板 | 审核日志/技能/知识、回答小院上报的问题 |
| 工作人员/技术员 | **工作日志**台 | 口述记台账、巡检看设备、群里问问题 |
| 农户 | 手机群里直接问 | 发消息给机器人（如「/技能 病虫害 叶子有褐斑」） |
| 学校/平台管理员 | 概览 + 小院监管 | 看全部小院日志量与断更预警 |

## 二、登录与账号

1. **打开系统**：浏览器访问管理员给你的网址（部署形态不同地址不同）。
2. **首次进入**：点击「注册」提交申请（管理员审批后生效）；或使用管理员发来的
   **邀请链接**直接加入对应小院。
3. **登录**：输入账号密码。连续输错会被暂时锁定（默认 10 次/5 分钟），稍后再试。
4. **忘记密码**：联系小院管理员在「成员管理」里重置。

> 角色由管理员分配，决定你能看到的菜单与操作权限（见附录 A 权限对照表）。

## 三、智能对话（所有人日常入口）

**入口**：左侧菜单「智能对话」。

- 新建会话：点左上角「+」；会话按主题自行命名。
- 提问：直接输入问题（如「水稻破口期什么时候打药」）。回答会**优先检索本小院
  知识库**，并附引用来源；引用不足时助手会如实说明并追问关键信息。
- **发附件**：支持 PDF/Word/Excel/图片/CSV 等，可让助手读取后分析（如上传田测
  照片、Excel 数据表）。文件类型不支持时会明确提示。
- **生成文档**：说「帮我整理成 Word/周报/PPT」，助手把内容落成可下载的文档
  （Word/Excel/PDF/Markdown），消息里出现下载卡。
- **一句话要技能**：说「我需要一个病虫害防治的技能」——系统先检索现成技能
  （列出候选卡片），没有合适的就自动生成一个草稿（私有，需审核后共享）。
- **一句话要插件**：说「做一个先查知识库再给灌溉建议的插件」——生成工作流
  插件草稿（一律待审核，不自动启用）。
- **转人工**：涉及用药/政策等高风险结论，助手会给出核实路径；重大问题建议
  在「专家审核/反馈」里上报，专家会回复。

## 四、指挥官工作台（把一个目标拆成任务自动执行）

**入口**：左侧菜单「指挥官工作台」。

1. **新建运行**：输入一句业务目标（如「整理本月病虫害防治情况并给出下月建议」）。
2. **计划确认**：系统先产出计划（可先追问你澄清问题）；你可编辑子任务后再执行。
3. **执行与观察**：点「执行」，右侧实时滚动每个子任务的进度与产出；运行中可
   取消、失败可重试（只重试失败的部分）。
4. **预算与成本**：每次运行显示 token 消耗与预算水位，超预算自动暂停并提示。
5. **资产沉淀**：成功的运行会沉淀「成熟工作流 / 技能片段 / 失败黑名单」，
   下次同类任务自动参考——越用越准。

> 执行器会使用发起人的权限，且**不放大权限**：高风险工具（如外呼类）仍需
> 按小院审批策略确认。发起人若被移出小院，在途运行会被立即终止。

## 五、工作日志（研究生/技术员每天用）

**入口**：左侧菜单「工作日志」（驻点成员登录后默认落地此页）。

### 5.1 生成日志草稿
1. 点「**生成今日草稿**」——系统把**你今天在平台上的真实活动**（咨询对话数、
   发起的任务、记的台账、设备操作等）自动汇总成一份客观的日志草稿。
2. **核对补充**：草稿只是底稿，务必补充平台之外发生的工作（如实地调查、
   农户访谈），删掉不符的条目。
3. 点「保存」；确认无误后点「**提交**」。

### 5.2 审核（专家/负责人/管理员）
- 列表切「全院」即可看到所有人的日志；「通过」或「驳回」（驳回必须填意见，
  作者会看到并修改后重新提交）。

### 5.3 月报与导出
- 点「生成本月月报草稿」：按本月日志自动聚合活跃天与要点，人工补充后提交。
- 点「**导出月报 Word**」：下载当月日志聚合成的 Word 文档，可直接贴进
  全国科技小院服务管理平台的填报表单。

### 5.4 考核进度
- 页面顶部四个卡片：本月日志篇数 / 已审核通过 / 活跃天数 / 月报草稿数——
  对应年度考核目标自查。

## 六、我的智能体（创建与管理你的专属助手）

**入口**：左侧菜单「我的智能体」。

### 6.1 ⚡ 一句话生成（最快的方式）
1. 点「**⚡ 一句话生成**」；
2. 输入一句需求（如「做一个病虫害防治智能体，能查知识库并给防治建议」），
   可点示例 chip 快速填入；选择可见性（私有/公开）；
3. 点「开始生成」→ 进度条展示四个阶段（检索资料→设计框架→匹配技能→保存草稿）；
4. 预览页展示**六段框架**（使命/服务对象/职责边界/工作流/护栏/产出格式）与
   「已匹配技能 / 待补技能」；
5. 点「完成」自动打开编辑弹窗，不满意可改（换了技能勾选、删掉待补项），
   保存后走**发布闸门**（草稿→审核→发布，不自动上线）。

> 配额：每人每天默认 10 次（负责人可在系统设置调整）。生成**不自动发布**。

### 6.2 手工创建
点「+ 新建智能体」：填编码/名称/系统提示词/任务模板（必须含 `{{question}}`
占位）、勾选扩展技能与插件、选知识范围（本小院/公开作物知识）。保存为草稿后
点「发布」——低风险直接发布，高风险进入平台审核。

### 6.3 智能体工厂（批量）
管理员用「智能体工厂批量生成」：输入行业描述 → 生成蓝图 → 勾选需要的角色
→ 一键装配，全部落为草稿待审。

### 6.4 协作班组
多个智能体可组成班组接力（如「设备解读员 → 农艺分析师 → 汇报撰写员」），
在「协作班组」里编排并运行。

## 七、插件与技能库（找能力 / 装能力 / 官方技能包）

**入口**：左侧菜单「插件与技能库」。

### 7.1 找现成的
- 「市场检索」标签：输入关键词检索内置技能 + 已缓存的开源技能；
- 点开条目看**来源、许可、风险等级**，点「安装」——第三方内容安装后**待审**，
  专家审核通过才可用。

### 7.2 官方技能包（推荐先用这个）
1. 负责人先到「系统设置 → 网络与搜索 → **小院画像**」勾选本小院产业类型
   （如水稻 + 水产）；
2. 回到技能库，**画像命中的官方包**会被标记推荐（如水稻包/水产蟹虾包）；
3. 点「启用」：包内技能（全部人工撰写、带公开权威来源、低风险只读）直接
   以已发布状态进入本院技能库，可被智能体绑定；
4. 平台升级带来新包时，同一按钮显示可更新，再点一次幂等更新。

### 7.3 自己导入
- 「上传 Skill 文件」（.md/.txt）与「上传插件包」（.zip）：导入后一律**待审**；
- 也可在对话里一句话生成（见三）。

## 八、专家审核（专家/负责人/管理员）

**入口**：左侧菜单「专家审核」。

- **知识候选**：自我总结/运维产生的知识候选，逐条或批量通过/驳回；
- **Skill 管理**：本院全部技能（含他人提交的），看定义、来源引用、风险等级；
  发布前若配置了评测门禁会自动跑用例；
- **工作日志**：新提交的日志在此「通过/驳回」（也可在工作日志页内操作）；
- 驳回必须填意见——作者会在自己的日志/草稿上看到意见。

## 九、自我升级（Evolution：让平台越用越强）

**入口**：左侧菜单「自我升级」（管理员/专家）。

- **插件注册与审核**：工作流插件（声明式步骤）注册后一律待审；审核通过才
  能运行；运行时每一步仍走工具权限与风险闸。
- **记忆与提案**：自我总结周期产生的偏好记忆、技能改进提案在此查看采纳。

## 十、设备与传感（有硬件的小院）

**入口**：左侧菜单「设备管理」。

- 绑定设备与传感器后，可在对话里问「现在大棚温湿度多少」「3 号塘溶氧怎么样」，
  智能体调用 `sensor.query` 工具读实时数据；
- 数据异常会按小院配置触发**分析任务**（可选 LLM 解释原因与建议）；
- 高危设备操作走审批闸（首次使用需管理员批准）。

## 十一、任务中心

**入口**：左侧菜单「任务中心」。

- 所有异步任务（一句话生成、指挥官、批量分析…）在此排队与追踪；

- 失败任务可「重试」；排队超时会被系统回收并标记原因。

## 十四、小院监管（学校/平台管理员）

**入口**：左侧菜单「小院监管」（仅平台管理员可见）。

- 表格列出**全部小院**：本月日志篇数、活跃作者数、最近更新时间；

## 十六、常见问题（FAQ）

**Q1 回答里说「依据不足」是缺点吗？**
不是。平台的设计原则是「不确定就追问、给结论必须给依据」。遇到这种情况，
补上关键信息（地块/生育期/症状照片）即可获得更准的回答。

**Q2 一句话生成的智能体/技能/插件会直接上线吗？**
不会。生成结果一律是**草稿或待审**，走发布/审核闸门后才可用。这是有意的
安全设计：自动化止步于草稿，启用永远经人。

**Q3 日志草稿里的内容不全？**
草稿只聚合**平台内的**活动。平台外的工作（下田、开会、电话指导）请务必
在编辑框里补充——提交前的内容以你确认的为准。

**Q4 搜索显示「联网受限/部分源不可用」？**
内置源以必应为主，搜狗/360 在部分网络下会被对方反爬拦截（显示不可用但不
影响使用）。需要更强搜索：系统设置里配一个 Tavily Key，或由管理员启用
本地 SearXNG（`docker compose --profile searxng up -d searxng`）。

**Q5 生成次数用完了？**
联系负责人调整「一句话生成智能体」的每人每日上限；指挥官运行另受 token
预算约束（设置里可调）。

**Q6 桌面小人不美观/不动了？**
小人会在发呆时自动表演「刨土→擦汗→摘草帽扇风→点头」；确认系统设置未开启
「减少动态效果」。8 套皮肤可在桌宠设置里切换。

## 十七、已知功能边界（诚实说明）

1. **官方模型购买**：目前只展示套餐与订单占位，**不会**完成真实支付或把订单
   标记为已支付——付费开通请联系线下渠道；
2. **搜索源**：搜狗/360 在部分网络环境被反爬拦截属正常现象，必应为主源可正常
   服务全部搜索功能；
3. **自动发布**：技能/插件/智能体的生成结果从不自动发布，所有共享动作都有
   人工审核环节——如遇「生成后不可用」，先到对应审核队列查看状态。
