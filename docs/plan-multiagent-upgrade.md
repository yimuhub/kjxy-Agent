## 关键设计约束（全波次通用）
- 工具执行一律走 `tool_registry.execute` 既有通道：校验→权限→风险闸→执行→审计，循环内不放行任何旁路。
- 副作用工具断点续跑**绝不重放**：retry 复用 ok 步 output_json。
- 新协议能力（function-calling/MCP）一律带 `supports_*` 能力位，老供应商零回归。
- 每波交付均含：迁移可逆实测、测试增量清单、openapi diff、真机冒烟记录。
- 借鉴来源与不采纳项见对标报告 §五（只借设计思想，无框架依赖搬运）。
