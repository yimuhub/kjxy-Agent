现状（对照）当前线上 v3.74 的观感
方案要点（确认后按此重造 design-system.css，版本 v3.75.0）： ① 分层——暗色卡片改「实色亮一档 + 顶部 1px 内高光 + 深阴影」浮出背景，亮色卡片改「纯白 + 双层柔和阴影」； 侧栏与主区拉开层级（暗色更深、亮色纯白）。② 色彩纪律——大数字回归中性主文本，语义色只出现在小徽章（8% 色底配方）， 全站渐变仍只允许主按钮 / 激活条 / logo。③ 氛围——暗色顶部靛紫光带加强，亮色配专属品牌氛围，告别灰蒙蒙。 ④ 弹层实色 + 大阴影。⑤ 约 20 个组件的硬编码色收敛回 token（桌宠造型与图表画布豁免）。
