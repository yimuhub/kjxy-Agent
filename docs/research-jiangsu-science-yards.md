# 江苏科技小院行业调研与官方技能库设计（2026-11-03）

> 调研方式：公开渠道（教育部/全国农指委/江苏省科协名录/新闻报道/高校管理办法）。
> 结论按「运行机理 → 数据与信息交换 → 江苏名录与产业分布 → 官方技能库设计」组织。

## 一、科技小院运行机理

### 1.1 制度框架
- **三部门顶层文件**：教育部、农业农村部、中国科协《关于支持建设科技小院的通知》
  （2024-04，moe.gov.cn/srcsite/A22/moe_826/202404/t20240415_1125626.html）：
  - 以**牵头院校为主体组建科技小院集群**，多学科联合攻关、技术转化推广；
  - **按服务对象分类共建**：依托地方政府、依托企业、依托合作社/园区等——这决定了
    平台需要同时面向「政府口」（汇报、考核）与「企业口」（产业问题、成本收益）；
  - 每院至少 1 位**首席专家**、专家团队不少于 2 人。
- **研究生培养模式**（2022-03 通知，moe.gov.cn/srcsite/A22/moe_826/202203/t20220322_609833.html）：
  农业专业学位研究生**长期驻点**生产一线，培养单位须有农业专业学位授权点、每单位 5 个以上小院。
- **管理结构**：高校普遍实行「学校（研究生院）—学院—小院」三级管理
  （湖南农大办法为典型）；江苏另有一层——**县级科协属地推荐、省科协联合多部门评审**
  （省级立项），形成「中国农技协科技小院联盟（国家级）/ 省级小院」双轨。

### 1.2 服务模式
- 「四零」服务：**零距离、零门槛、零时差、零费用**（榆林学院办法原文；全国通行口径）；
- 「科研攻关 + 技术培训 + 示范推广」三段式：示范田建在农民身边，小院既是研究生
  学业现场，又是农民培训站（南农梨科技小院、南大综述等案例）；
- 江苏整体盘子（截至 2025-05，jschina.com.cn）：指导老师 **825 人**、驻点研究生 **747 人**、
  推广新技术 **392 项**、培训农民 **32000+ 人次**、田间示范基地 **740+ 个 / 3.2 万亩**。

## 二、信息与数据交换（平台化现状）

1. **全国科技小院服务管理平台**（stb.mae.edu.cn，全国农指委运营）：
   - 研究生**工作日志 + 月报**在此填报；
   - 设**日志排行榜**（如云南晋宁 3534 篇、甘肃甘州 2233 篇）——日志数量被显性竞赛化；
   - 高校专项通知（南通大学 2026-10、内蒙古科技大学）：管理员须**核查重复/应付式日志**，
     **日志数量、质量、驻点时长直接挂钩研究生实践考核与小院年度评价**；
   - 《科技小院农业专业学位研究生培养质量监测标准（试行）》以日志/月报为重要监测依据。
2. **数据流向**：研究生（一线生产数据/试验记录）→ 小院管理员（高校）核查 → 全国平台；
   考核结果反向驱动填报行为。**存在明显痛点**：日志以纯文本填报为主，田间数据
   （传感器/测土/试验小区）与日志脱节，重复劳动、应付式填报被点名整治。
3. **对我们的定位启示**：本平台的「会话台账/任务记录/指挥官周报」恰好对应
   「日志→月报→年度评价」链条的数字化升级；**报告一键导出与自动推送**直接命中
   该考核体系的一线痛点（见 pain-points-plan 痛点二/五）。

**对技能包设计的直接含义**：江苏小院产业高度集中于「稻麦、水产品蟹虾、应时鲜果、

「小院类型」组织即可覆盖 89 家的绝大多数。

## 四、官方技能库设计（方案）

### 4.1 分发模型（复用现有 builtin 机制，不做中央服务器）

平台是自托管交付，不存在常驻中央云端——「官方更新」落在**代码仓库 + 发版**：

```
backend/app/modules/market/official_packs/
  ├── index.yaml                    # 目录：包清单 + 版本 + 适用小院类型
  ├── rice/                         # 水稻/稻麦族
  │   ├── pack.yaml                 # 版本、适用类型、技能/插件/知识清单
  │   ├── skills/*.md               # 技能定义（skill-template/v3.2 格式）
  │   └── knowledge/*.md            # 内置知识文档
  ├── crab_shrimp/  grape/  tea/  livestock/  vegetable/  sericulture/  smart_agri/
  └── common/                       # 全类型通用（台账/汇报/培训）
```

- **内置打包**：与 `ensure_builtin_skills`（12 个内置技能）同机制升级为**多包 + 类型标签**；
  导入走现有安装闸（builtin 直通 published，人工内容不经过生成链路）。
- **按小院类型启用**：小院设置新增 `yard_profile`（从上表 8 类选一或多选），
  「官方技能库」页按 profile 推荐 + 一键启用，未启用包不占技能列表。
- **官方更新通道**：包内容随平台 release 版本化；设置页显示「官方包 vX.Y → vX.Z 有更新」，
  负责人一键升级（幂等重导入，published 覆盖，保留用户绑定）。
- **针对性更新**：省级科协发布新名录/新产业时，官方在下一个 release 中新增包目录；
  用户侧无任何中央依赖。

### 4.2 首批内容（按调研分布，v1 覆盖六大族 + common）

- `common`：农事台账问答、农民培训课件大纲、对上汇报材料（呼应痛点五）
- `rice`：分期水肥管理、病虫害（二化螟/稻飞瘟/纹枯）识别防治、富硒栽培要点
- `crab_shrimp`：河蟹蜕壳期管理、塘口水质调控、投喂与水草平衡、发病应急
- `grape`：花果管理、霜霉/灰霉防治、套袋与采收标准
- `vegetable`：设施温湿度调控、黄瓜/番茄常见病害、萝卜肉质根管理
- `tea`：采摘标准与WithName加工、茶小绿叶蝉防治
- `livestock`：蛋鸡/肉鸭饲喂与疫病防疫日历、山羊圈舍管理
- `smart_agri`：传感器数据解读（对接本平台 devices 数据）、异常告警处置

每包 3~5 个技能，全部人工撰写（不走生成链路），带 `sources`（公开权威来源链接）、
`eval_cases`≥2、适用机型口径为「知识检索 + 可选 web.search」低风险只读。

### 4.3 分期

- **P0**（本迭代）：目录结构 + yard_profile 设置 + 导入器扩展 + common/rice 两包打样，
  验证「类型推荐 → 一键启用 → 更新提示」闭环。
- **P1**：其余六包内容（人工撰写为主，可按调研来源带引用）。
- **P2**：知识种子包（A5）并入各包 `knowledge/`；推送通道按包发布通知（呼应痛点二）。
